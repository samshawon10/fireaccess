# Changelog

All notable changes to FireAccess will be documented in this file.

## 1.0.2 - 2026-06-02

### Added

* Added npm package, GitHub repository, issues, and changelog links to the README.
* Added `CONTRIBUTING.md`.
* Added `CHANGELOG.md`.

### Improved

* Expanded README documentation for RBAC, permissions, audit logging, configuration, TypeScript support, error responses, development, publishing, and security.

## 1.0.0 - 2026-06-02

### Added

* Initial FireAccess package release.
* Firebase Admin SDK token verification.
* MongoDB user synchronization.
* Express authentication middleware.
* Role-Based Access Control (RBAC).
* Permission-Based Access Control.
* Audit logging middleware.
* TypeScript request augmentation for `req.user` and `req.firebaseUser`.
* ESM and CommonJS builds.
