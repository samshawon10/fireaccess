## Start

1. Copy `.env.example` to `.env`.
2. Fill Firebase and MongoDB values.
3. Run `npm install`.
4. Run `npm run dev`.

The backend starts on `http://localhost:4000` and the frontend starts on `http://localhost:5173`.

## What Is Included

- Express API with FireAccess middleware.
- Firebase Admin token verification.
- MongoDB user sync and inactive user blocking.
- RBAC and permission middleware.
- Audit log persistence.
- React + Tailwind admin dashboard.
- User table, role editor, permission matrix, audit viewer, and search.
